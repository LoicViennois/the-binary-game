# The Binary Game

<a href="https://binary.loicviennois.com/" target="_blank"><img src="public/icons/icon-192x192.png" width="192" alt="logo" /></a>

The Binary Game is a game to play with binary numbers, solo or with friends !

The Binary Game is a static single-page app built with [React](https://react.dev), [TanStack Router](https://tanstack.com/router), [Tailwind CSS](https://tailwindcss.com) and [Vite](https://vite.dev), deployed on Vercel.

## Development

```bash
pnpm install
pnpm dev     # dev server on http://localhost:5173
pnpm build   # type-check and build to dist/
pnpm lint
pnpm e2e     # Playwright end-to-end tests
```
